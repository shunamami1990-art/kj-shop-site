## 背景

2026-11-15 负责人在示例站试下单：平台返回 `PAY_METHOD_UNAVAILABLE`（店铺码不足），买家在下单页看到了提示，但之后打开"我的订单"的订单页只显示"订单尚未提交到平台"，看不出是被平台拒绝、拒绝的原因是什么，排查要去平台后台。

## 要做的

1. `lib/db.js` 的 `orders` 表加两列 `last_error_code TEXT`、`last_error_text TEXT`（`ALTER TABLE ... ADD COLUMN` 按现有"IF NOT EXISTS / 启动时补列"的做法，已有数据库升级后能用）。
2. `lib/orders.js` 提交订单到平台被**明确拒绝**（`businessErrorStatus` 这一支，不是结果未知那一支）时，把平台的错误码和 `errorText` 的说明写到这两列；再次提交成功时清空。结果未知、签名错误（`KjSignatureError`）不写（保持现有处理）。
3. 订单页 `app/orders/[no]/page.jsx`：没有平台订单号且有 `last_error_code` 时，把"订单尚未提交到平台。"改为"平台拒绝了这笔订单：<说明>（错误码 <code>）"；买家能再次下单的话给"重新下单"的链接（已有的话不重复加）。
4. 测试（`test/`）：拒绝后订单页显示错误码和说明；结果未知不写；再次成功后清空。
5. `docs/design.md` 订单一节补这两列和显示规则，"依据"升到 0.16.1。
6. `CLAUDE.md` 第 8 节的表加一行：`| 原地修改本文件夹里的文件 | `sed -i ... <本文件夹内的文件>`（路径检查核对；宿主机上执行代码的 python3 等仍不放行） |`（权限已放行，B-91）。
